# Private beta checklist

- Complete the GitHub and WorkOS guides with separate staging credentials.
- Apply migrations and run configuration validation plus the deployment dry run.
- Verify OIDC and project-token upload, deduplication, reruns, matrix shards, PR close/reopen, and baseline rollback/resume.
- Test opaque IDs across two organizations and confirm cross-tenant access fails.
- Exercise export, deletion cancellation, and completed deletion in a disposable organization.
- Complete the backup restore exercise and reconcile image-byte accounting.
- Run staged load progression and record safe quotas.
- Assign alerts for exhausted jobs, unresolved PR retention, 5xx responses, quota pressure, and deletion failures.
- Publish support, privacy, incident, and retention contacts.

Onboard repositories one at a time. Record time-to-first-report, upload failures, review performance, baseline surprises, and support issues. Do not raise ceilings until measurements and cost estimates justify the change.
